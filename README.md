# ☕ Treinando Java — Beecrowd

Repositório com exercícios do [Beecrowd](https://www.beecrowd.com.br) resolvidos em Java, organizados por categoria.

## 📁 Estrutura

```
src/
└── exercicios/
    ├── introducao/         → Exercícios 
    ├── condicionais/       → Exercícios 
    ├── loops/              → Exercícios 
    ├── strings/            → Exercícios com manipulação de texto
    ├── vetores/            → Exercícios com arrays unidimensionais
    └── matrizes/           → Exercícios com arrays bidimensionais
```

## 🚀 Como rodar

1. Abrir o projeto no **IntelliJ IDEA**
2. Navegar até o exercício desejado em `src/exercicios/`
3. Abrir o arquivo `.java` e pressionar **Shift + F10**
## 🧠 Sobre

- **Linguagem:** Java
- **Plataforma:** [Beecrowd](https://www.beecrowd.com.br)
- **Objetivo:** Praticar lógica de programação e sintaxe Java vindo do C
